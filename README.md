# BRD4 in the heart: public data reanalysis

Static Artemis Biolabs portal. The analyses shown use only public data (GEO GSE48112, GSE96566, GSE138210, GSE141910; the Reichart et al. 2022 heart cell atlas; the HERMES DCM GWAS, Zheng et al. 2024; MitoCarta3.0; the Padmanabhan et al. 2020 Circulation supplement). Earlier reports shared privately with the lab are only described, with no results. Served with GitHub Pages; open `index.html` through any static server to run locally. No API key is stored in this folder.

Prepared by Logan Beharry, Founder, Artemis Biolabs. Independent analysis, not affiliated with or endorsed by the Padmanabhan Lab or UCSF. Research use only.
